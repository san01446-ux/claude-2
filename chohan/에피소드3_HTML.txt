<p style="margin:0 0 16px;">해하의 진영은 얼어붙어 있었다.<br><br>군량은 바닥났고, 병사들은 말의 안장 가죽을 삶아 먹었다. 한신의 군이 겹겹이 둘러싼 지 여러 날. 횃불이 산등성이마다 별처럼 박혀 있었다.</p><p style="margin:0 0 16px;">밤이 깊었을 때였다.<br><br>어디선가 노래가 들려왔다. 처음엔 한 줄기. 이어 동쪽에서, 서쪽에서, 남쪽에서, 북쪽에서.</p><p style="margin:0 0 16px;">초나라의 노래였다.<br><br>고향의 가락. 어머니가 부르던 노랫말.</p><p style="margin:0 0 16px;">막사 곳곳에서 창이 땅에 떨어지는 소리가 났다. 누군가 흐느꼈다. &quot;한이 벌써 초 땅을 다 얻었단 말인가. 어찌 초나라 사람이 저리도 많은가…&quot;</p><p style="margin:0 0 16px;">본진의 큰 장막 안에서 항우가 술을 따랐다. 곁에는 우희가 앉아 있었다. 오추마가 밖에서 길게 울었다.</p><p style="margin:0 0 16px;padding-left:12px;border-left:2px solid #9b2c22;color:#3a2a1c;font-weight:bold;">&quot;힘은 산을 뽑고 기개는 세상을 덮었건만…&quot;<br><br>노래는 그치지 않는다.<br><br>그리고 당신은 이 포위된 밤 속에 있다.</p>
