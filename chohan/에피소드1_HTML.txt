<p style="margin:0 0 16px;">장맛비가 열흘째 그치지 않았다.<br><br>기현 대택향의 진흙 들판. 어양으로 수자리 가던 장정 구백 명이 비에 갇혀 발이 묶였다. 기한 안에 닿지 못하면 진의 법은 하나다. 모두 참수.</p><p style="margin:0 0 16px;">막사 안에는 젖은 짚 냄새와 쉰 땀 냄새가 고여 있었다. 누군가는 울었고, 누군가는 주먹밥 반쪽을 두고 칼을 만졌다.</p><p style="margin:0 0 16px;">그때 둔장 진승이 일어섰다. 마른 얼굴에 눈만 이글거렸다.</p><p style="margin:0 0 16px;padding-left:12px;border-left:2px solid #9b2c22;color:#3a2a1c;font-weight:bold;">&quot;어차피 늦으면 죽는다. 도망쳐도 죽는다. 같은 죽음이라면, 나라를 세우다 죽는 게 낫지 않겠는가!&quot;</p><p style="margin:0 0 16px;">옆에서 오광이 술 취한 척 장교의 칼을 걷어찼다. 칼이 진흙 위에 떨어졌다. 구백 개의 눈이 한꺼번에 그 칼을 보았다.</p><p style="margin:0 0 16px;padding-left:12px;border-left:2px solid #9b2c22;color:#3a2a1c;font-weight:bold;">&quot;왕후장상의 씨가 어찌 따로 있겠는가!&quot;</p><p style="margin:0 0 16px;">함성이 빗소리를 찢었다.<br><br>그리고 당신은 — 그 막사 한가운데 서 있다.</p>
