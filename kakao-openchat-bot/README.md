# 오픈채팅방 관리 봇 (메신저봇R)

안드로이드 앱 **메신저봇R**에 넣어 쓰는 스크립트입니다. 파일 하나(`bot.js`)로 동작합니다.

## 기능
| 명령어 | 설명 |
|---|---|
| `!출석` | 하루 한 번 출석. 오늘 몇 번째인지, 누적·연속 출석일 표시 |
| `!출석현황` | 오늘 출석한 사람 목록 |
| `!미출석` | 오늘 출석 안 한 사람 목록 (봇이 한 번이라도 본 멤버 기준) |
| `!출석순위` | 누적 출석 순위 |
| `!비활동` / `!비활동 14` | N일 이상 대화 없는 멤버 (기본 7일) |
| `!대화순위` | 메시지 수 순위 |
| `!끝말잇기` / `!끝말잇기 종료` | 끝말잇기. 두음법칙 인정, 중복 단어·연속 차례 금지 |
| `!초성게임` / `!힌트` / `!패스` / `!초성게임 종료` | 초성 퀴즈 5문제 (음식·동물·과일·나라·직업·물건) |
| `!게임순위` | 끝말잇기·초성게임 누적 점수 |
| `!도움말` | 명령어 안내 |

## 설치
1. 봇으로 쓸 **안드로이드 폰**에 카카오톡을 설치하고 **봇 전용 카카오 계정**으로 로그인합니다. (본인 메인 계정 사용 비추천)
2. 그 계정으로 오픈채팅방에 들어갑니다.
3. 플레이스토어에서 **메신저봇R** 설치 → 앱 실행 → 「알림 접근 권한」 허용.
4. 카카오톡 설정에서 **알림 켜기** (해당 오픈채팅방 알림도 켜져 있어야 함).
5. 메신저봇R에서 **봇 추가 → 레거시 API** 선택 → `bot.js` 내용을 통째로 붙여넣고 저장 → **컴파일** → 봇 스위치 ON.
6. `bot.js` 맨 위 `CONFIG.rooms` 에 방 이름을 넣으면 그 방에서만 반응합니다. 예: `rooms: ["우리 오픈채팅방"]`
7. 방에서 `!도움말` 을 쳐서 응답이 오면 완료.

폰은 **충전기에 꽂아 두고 24시간 켜 두어야** 합니다. 배터리 최적화에서 메신저봇R과 카카오톡을 제외해 주세요.

## 한계 (고객에게 미리 안내)
- **입장 횟수 기록은 불가**: "OO님이 들어왔습니다" 같은 시스템 메시지는 알림으로 오지 않아서, 루팅 없이는 봇이 볼 수 없습니다. 대신 출석·비활동 기록으로 활동을 관리합니다.
- **닉네임 기준**: 오픈채팅 닉네임을 바꾸면 다른 사람으로 기록됩니다.
- **미출석 목록**: 카카오톡이 멤버 목록을 주지 않아서, 봇이 켜진 뒤 한 번이라도 말한 사람만 압니다.
- **끝말잇기 단어 검사**: 사전 검사는 하지 않습니다(끝 글자 연결·중복만 확인).
- **카카오 정책**: 카카오톡은 공식적으로 자동응답 봇을 허용하지 않습니다. 봇 계정이 제재될 수 있으므로 반드시 봇 전용 계정을 쓰세요.

## PC에서 미리 써 보기
`simulator.html`을 브라우저로 열면 카카오톡 없이 봇을 써 볼 수 있습니다. 보내는 사람을 바꿔 가며 테스트하고, 「하루 지나기」로 출석·비활동을 확인합니다. (`bot.js`를 그대로 담고 있으므로 `bot.js`를 고치면 시뮬레이터도 다시 만들어야 합니다.)
