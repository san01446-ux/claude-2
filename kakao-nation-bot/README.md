# 가상국가 운영 봇 (메신저봇R)

카카오톡 오픈채팅 가상국가 방에서 쓰는 운영 봇입니다. `bot.js` 파일 하나로 동작합니다.

## 기능
| 분류 | 명령어 |
|---|---|
| 국민 | `!국민등록` `!신분증 [닉네임]` `!국민목록` |
| 화폐 | `!잔고 [닉네임]` `!송금 닉네임 금액` `!월급`(하루 1번, 관직별 금액) `!재산순위` |
| 출석 | `!출석`(보상 지급) `!출석현황`(출석/미출석) |
| 나라 | `!국가정보` `!헌법` `!공지` `!관직목록` |
| 투표 | `!투표현황` `!투표 번호` |
| 선거 | `!선거현황` `!출마` `!선거투표 후보` — 종료 시 당선자가 관직에 자동 임명 |
| 요약 | `!요약`(내가 마지막으로 말한 뒤 쌓인 대화) `!요약 100`(최근 100개) |
| 관리 | `!공지등록` `!공지삭제` `!지급` `!회수` `!관직임명` `!관직해임` `!투표생성 제목 \| 항목 \| 항목` `!투표종료` `!선거시작 관직` `!선거종료` |

관리 명령은 관직 권한이 있는 사람만 쓸 수 있고, `!도움말`에 내 권한으로 쓸 수 있는 명령만 보입니다.
닉네임에 띄어쓰기가 있어도 됩니다. (예: `!송금 달빛 고양이 100`)

## 설정 (`bot.js` 맨 위 CONFIG)
- `nation`: 나라 이름, 화폐 이름, 건국일, 표어, 헌법 조항
- `admins`: 모든 권한을 가진 운영자 닉네임 (처음 세팅용)
- `roles`: 관직 이름, 권한(`notice` 공지, `money` 지급·회수, `appoint` 임명, `vote` 투표, `election` 선거, `*` 전부), 정원, 하루 월급
- `startBalance`: 국민등록 지원금 / `attendanceReward`: 출석 보상
- `summary.apiKey`: OpenAI API 키. 비워 두면 요약 기능이 꺼집니다.

## 설치
1. 봇용 안드로이드 폰에 카카오톡 설치 → **봇 전용 계정**으로 로그인 → 나라 오픈채팅방 입장
2. 메신저봇R 설치 → 알림 접근 권한 허용 → 카카오톡·해당 방 알림 켜기
3. 메신저봇R에서 봇 추가(레거시 API) → `bot.js` 내용 붙여넣기 → CONFIG 수정 → 컴파일 → 켜기
4. 방에서 `!도움말` 입력해서 답이 오면 완료
5. 폰은 충전기에 꽂아 계속 켜 두고, 배터리 최적화에서 카카오톡·메신저봇R 제외

## 꼭 안내할 점
- **요약 기능**은 방 대화를 폰에 저장하고 요약할 때 OpenAI로 보냅니다. 방 공지로 멤버들에게 알려 주세요. 원치 않으면 `summary.enabled: false`.
- AI 이용료는 OpenAI 계정에 사용량만큼 청구됩니다.
- 닉네임 기준으로 기록하므로 닉네임을 바꾸면 다른 사람으로 인식됩니다.
- 카카오가 공식 지원하는 방식이 아니어서 봇 계정이 제재될 수 있습니다. 반드시 봇 전용 계정을 쓰세요.
