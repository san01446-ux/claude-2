# 천하제일 무림 (天下第一武林)

브라우저에서 바로 실행되는 3D 무협 액션 게임입니다. Three.js 기반이며 빌드 과정이 없습니다.

마교의 무리가 청운산을 침범했습니다. 청운검객이 되어 끝없이 몰려오는 적을 물리치고, 다섯 번째 파(波)마다 등장하는 마교 교주를 쓰러뜨리세요.

## 실행 방법

ES 모듈을 사용하므로 `file://`로 열면 동작하지 않습니다. 로컬 서버로 실행하세요.

```bash
python3 -m http.server 8000
# 또는
npx serve .
```

그 다음 브라우저에서 <http://localhost:8000> 을 엽니다. three.js는 `lib/`에 포함되어 있어 오프라인에서도 동작합니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 시점 회전 (휠: 줌) |
| 좌클릭 / J | 검법 — 3연격 콤보 (마지막 타는 회전베기) |
| 우클릭 / K | 장풍 — 관통하는 기공탄 (내공 25) |
| Space | 도약, 공중에서 한 번 더 누르면 경공 이단 도약 (내공 10) |
| Shift | 보법 — 무적 대시 (내공 15) |
| Q | 천뢰검 — 내공이 가득 찼을 때 도약 후 내려찍어 주변 적에게 낙뢰 (내공 100) |
| Esc / P | 일시정지 |

## 게임 시스템

- **내공**: 시간이 지나면 회복되고, 적을 베거나 처치하면 추가로 차오릅니다. 가득 차면 몸에 푸른 기운이 감돕니다.
- **적**
  - 산적 — 기본 적
  - 흑도 무사 — 빠르고 강함 (3파부터)
  - 마교 교주 — 5파마다 등장하는 보스. 붉은 원으로 예고한 뒤 도약해 내려찍기를 쓰므로 보법이나 경공으로 피하세요.
- 적이 붉게 빛나면 공격 직전입니다. 보법으로 회피하세요.
- 적이 가끔 떨어뜨리는 초록 구슬을 먹으면 체력이 회복되고, 한 파를 막아낼 때마다 체력이 회복됩니다.
- **무공 비급**: 한 파를 막아낼 때마다 비급 3개 중 하나를 골라 익힙니다 (클릭 또는 1·2·3). 같은 비급을 여러 번 익히면 성(단계)이 오릅니다.

  | 비급 | 효과 (1성당) |
  | --- | --- |
  | 검기 강화 劍氣 | 검법 피해 +20% |
  | 금강불괴 金剛不壞 | 최대 체력 +25 |
  | 소주천 심법 小周天 | 내공 회복 +40% |
  | 흡성대법 吸星大法 | 적 처치 시 체력 +3 |
  | 이형환위 移形換位 | 이동 속도 +10%, 보법 내공 -4 |
  | 항룡장 降龍掌 | 장풍 피해 +30%, 크기 +20% |
  | 벽력검 霹靂劍 | 치명타 확률 +8% |
  | 호신강기 護身罡氣 | 받는 피해 -12% |
  | 검강 劍罡 | 3타 회전베기가 관통하는 검기 파동을 날림 |
- 최고 기록(도달한 파, 명성)은 브라우저에 저장됩니다.

## 구조

```
index.html      HUD / 메뉴
style.css       UI 스타일
js/main.js      월드, 캐릭터, 전투, 적 AI, 웨이브, 카메라
js/assets.js    텍스처·HDRI 로더
js/audio.js     WebAudio 절차적 효과음 (에셋 파일 없음)
assets/         텍스처(CC BY 4.0), HDRI(CC0), 한글 글꼴(OFL), UI 일러스트(PixAI 생성) — 출처는 CREDITS.md
lib/            three.js r160 + EXRLoader (MIT)
tools/          글꼴 서브셋 스크립트
```

캐릭터와 건물(정자, 일주문, 대나무 숲, 석등 등)은 코드로 생성하고, 지면·석판·바위·목재 텍스처, 환경광, 글꼴은 무료 라이선스 에셋을 씁니다. 출처와 라이선스는 [CREDITS.md](CREDITS.md)에 정리되어 있습니다.

UI 문구를 새로 추가하면 글꼴 서브셋에 없는 글자는 기본 글꼴로 표시됩니다. 이때는 `tools/subset_fonts.py`를 다시 실행하세요 (사용법은 스크립트 상단 참고).
