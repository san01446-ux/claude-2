진행 방식

완성된 테스트 화면을 먼저 보시고 결제합니다.

  1. 상담업종, 원하는 기능, 사용할 플랫폼을 여쭤봅니다.
  2. 견적 확정기능 범위, 금액, 일정을 정리해 드립니다.
  3. 정보 전달양식에 영업시간, 메뉴, 자주 받는 질문을 채워 주시면 됩니다.
  4. 제작·테스트기본형은 2~4일 안에 테스트 화면을 보여 드립니다.
  5. 배포·결제수정 사항을 반영해 실제 채널에 연결한 뒤 결제합니다.
  6. 사후 관리배포 후 2주 동안 오류는 무료로 고쳐 드립니다.
