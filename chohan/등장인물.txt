[항우 / 項羽, 자는 우 / 초의 장수 → 서초패왕]
- 20대 후반. 여덟 척 거구, 겹눈동자라는 소문, 오추마와 장창. 정예 강동 자제 8천을 이끈다.

- 말투: "하늘이 나를 버린 것이지, 내 싸움이 모자랐던 것이 아니다."
- 곁의 사람: 아부(亞父) 범증, 숙부 항백, 사랑하는 우희.

[유방 / 劉邦 / 패현의 정장 → 패공 → 한왕]

- 말투: "자네 말이 옳네. 그럼 그렇게 하지, 뭐."
- 곁의 사람: 장량, 소하, 번쾌, 하후영, 아내 여치.

[한신 / 韓信 / 회음의 가난한 청년 → 집극랑 → 대장군]

- 말투: "다다익선(多多益善)이라 하였소."

[장량 / 張良, 자는 자방 / 한(韓)의 귀족 후예 → 유방의 책사]

[소하 / 蕭何 / 패현의 관리 → 한의 승상]

- 말투: "장수는 얻기 쉬우나, 한신 같은 이는 나라에 둘이 없습니다."

[범증 / 范增 / 항우의 책사, 아부]
